# 七七真实内容资产池 PRD

## 产品定位

七七灵感池从“灵感记录工具”升级为“七七真实内容资产池”。

它承接的不是单条备忘录，而是可以进入内容生产链路的真实素材，包括语音灵感、文本灵感、截图素材、客户沟通记录、项目复盘、行业观察、AI 热点来源和公众号文章素材。

核心目标是把七七的真实观察与 AI 抓取的热点融合，生成更像七七本人的公众号选题和文章。

## 阶段定义

### V1

网页文字倾倒、网页手动保存、localStorage 保存。

### V2

网页端语音输入、浏览器录音 / Web Speech API 语音转文字方案、上传图片/截图/文本素材入口、素材备注和归档。

### V3

飞书语音输入、飞书素材同步、飞书自建应用/事件订阅、跨设备同步数据库。

## 当前推荐顺序

1. 先做网页文字倾倒和候选灵感整理。
2. 再做 Web Speech API 轻量语音输入。
3. 再做文本素材与图片素材入口。
4. 最后再评估 Whisper、飞书自建应用和跨设备数据库。

## 当前边界

- 不接数据库。
- 不接真实语音识别 API。
- 不接 OCR。
- 不接飞书同步。
- 不接真实平台热点接入。
- 不新增 AI Provider。
- 不改公众号上传、草稿箱、飞书推送、Vercel Cron 主链路。

## 现阶段用户路径

1. 用户把原始灵感、语音转写文本或素材说明输入到收件箱。
2. AI 将原始内容拆成候选灵感。
3. 用户确认入池、编辑后入池或丢弃。
4. 入池后保存到 `qiqi_inspiration_pool_v1`。
5. 灵感可与今日热点或来源池融合，进入公众号选题和文章生成链路。

## 设计原则

- 不把个人观察伪装成真实热点。
- 不让用户先填表再思考。
- AI 只做拆分、命名、分类、归档辅助，不替代七七判断。
- 所有高风险能力先留在方案层，等到边界足够清晰再进入实现。
