# 七七内容雷达路线图

## V1 已完成

- 线上部署。
- 飞书推送。
- 公众号本地写入。
- 公众号排版。
- 来源管理器。
- 今日选题。
- 飞书卡片公网工作台入口。

## V2 近期

- 灵感池。
- 灵感评分。
- 灵感转选题。
- 灵感转大纲。
- 灵感转公众号正文。
- 飞书每日 8 点稳定自动推送验收。

V2 的核心目标是把零散灵感变成可写、可评分、可转文章的内容资产。

## V3 中期

- 语音输入灵感。
- 飞书灵感同步。
- AI 自动封面。
- 国内数据源接入：新榜、巨量、小红书观察、抖音指数。

V3 的核心目标是提高输入效率和外部信号质量，但不能把未真实接入的数据源包装成真实热点。

## V4 长期

- 固定 IP 云服务。
- 线上稳定写入公众号草稿箱。
- 飞书交互卡片。
- 多平台矩阵自动生成。
- 私域承接素材自动生成。

V4 的核心目标是完成从内容生产到多平台分发、私域承接和线上发布链路的稳定闭环。
## v3.3-1B-FIX 七七灵感池 V1

状态：已完成。

范围：

- 首页新增“七七灵感池”入口。
- 支持手动输入灵感并保存到 `qiqi_inspiration_pool_v1`。
- 支持灵感列表、类型筛选、复制、归档、删除。
- 支持一键转成公众号选题，复用现有生成大纲 / 生成正文主流程。

未包含：

- 不接数据库。
- 不接飞书灵感同步。
- 不做 AI 评分。
- 不接真实平台来源。
- 不改公众号上传、草稿箱、飞书推送、Vercel Cron 主链路。

## v3.3-1B-UX-FIX 七七灵感池倾倒式收件箱

状态：已完成。

范围：

- 将灵感池主入口从手动表单改为大文本框倾倒式输入。
- 新增 `inspirationAnalyze` AI 任务，复用现有 AI route 和 Provider。
- 展示待确认候选灵感，支持确认入池、编辑后入池、丢弃和全部确认。
- 保留手动保存兜底与高级编辑 / 手动补充。
- 入池后继续保存到 `qiqi_inspiration_pool_v1`，并保留转公众号选题入口。

未包含：

- 不新增数据库。
- 不新增依赖。
- 不接语音输入。
- 不接飞书灵感同步。
- 不做真实平台热点接入。
- 不改公众号上传、草稿箱、飞书推送、Vercel Cron 主链路。

## v3.3-1C-PREP 七七灵感池升级 PRD

状态：进行中。

范围：

- 设计语音输入、素材上传、灵感与热点融合成选题/文章的方案。
- 定义 V1 / V2 / V3 输入通道。
- 设计热点 × 灵感 融合评分与文章使用计划。
- 扩展 InspirationItem 和 Topic 数据结构。
- 明确飞书语音输入属于 V3，不进入当前开发。

下一步任务拆分：

- `v3.3-1D-FIX`：网页端语音输入轻量版 Web Speech API
- `v3.3-1E-FIX`：素材上传入口与文本素材归档
- `v3.3-1F-FIX`：灵感与今日选题匹配，生成融合推荐
- `v3.3-1G-FIX`：文章大纲中标注可使用灵感
- `v3.3-1H-FIX`：正文生成时嵌入真实灵感
- `v3.3-2A-PREP`：飞书语音输入技术方案
- `v3.3-2B-PREP`：跨设备数据库方案
