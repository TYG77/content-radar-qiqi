# 七七内容雷达路线图

## V1 已完成

- 线上部署。
- 飞书推送。
- 公众号本地写入。
- 公众号排版。
- 来源管理器。
- 今日选题。
- 飞书卡片公网工作台入口。

## V2 近期

- 灵感池。
- 灵感评分。
- 灵感转选题。
- 灵感转大纲。
- 灵感转公众号正文。
- 飞书每日 8 点稳定自动推送验收。

V2 的核心目标是把零散灵感变成可写、可评分、可转文章的内容资产。

## V3 中期

- 语音输入灵感。
- 飞书灵感同步。
- AI 自动封面。
- 国内数据源接入：新榜、巨量、小红书观察、抖音指数。

V3 的核心目标是提高输入效率和外部信号质量，但不能把未真实接入的数据源包装成真实热点。

## V4 长期

- 固定 IP 云服务。
- 线上稳定写入公众号草稿箱。
- 飞书交互卡片。
- 多平台矩阵自动生成。
- 私域承接素材自动生成。

V4 的核心目标是完成从内容生产到多平台分发、私域承接和线上发布链路的稳定闭环。
## v3.3-1B-FIX 七七灵感池 V1

状态：已完成。

范围：

- 首页新增“七七灵感池”入口。
- 支持手动输入灵感并保存到 `qiqi_inspiration_pool_v1`。
- 支持灵感列表、类型筛选、复制、归档、删除。
- 支持一键转成公众号选题，复用现有生成大纲 / 生成正文主流程。

未包含：

- 不接数据库。
- 不接飞书灵感同步。
- 不做 AI 评分。
- 不接真实平台来源。
- 不改公众号上传、草稿箱、飞书推送、Vercel Cron 主链路。
