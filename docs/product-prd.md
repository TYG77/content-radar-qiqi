# 陈七七77 内容选题雷达工作台 PRD

## 产品名称

- 陈七七77 内容选题雷达工作台
- 七七女性健康 IP 内容与私域增长工作台

## 产品定位

面向女性健康营养师、大健康 IP 操盘手和内容/私域增长操盘者的内容生产与私域增长工作台。

工作台不是单点写作工具，而是把灵感、来源证据、行业观察、AI 判断、公众号文章、排版、飞书提醒和后续私域承接串成一条稳定内容生产链路。

## 目标用户

- 当前核心用户：陈七七
- 后续可扩展用户：大健康 IP、营养师、中医、健康管理类账号、健康内容团队

## 核心价值

- 降低内容选题成本，让每天值得写什么更清楚。
- 把灵感变成可判断、可评分、可写成文章的选题。
- 把行业观察和来源证据变成可发布内容，而不是停留在碎片记录。
- 把公众号文章和私域转化连接起来。
- 让内容生产有来源、有判断、有排版、有承接。
- 形成符合七七表达风格和专业底线的长期内容资产。

## 当前核心流程

1. 今日选题
2. 来源证据
3. AI 评分
4. 生成大纲
5. 生成正文
6. 七七语气优化
7. 公众号排版
8. 飞书提醒
9. 公众号草稿箱

## 未来核心流程

1. 灵感池
2. 灵感评分
3. 灵感转选题
4. 灵感转文章
5. 多平台矩阵
6. 私域承接

长期完整链路：

灵感记录 -> AI 分析灵感 -> 灵感评分 -> 灵感筛选为选题 -> 结合热点和来源证据 -> 生成公众号大纲 -> 生成公众号正文 -> 七七语气优化 -> 自动排版 -> 进入公众号草稿箱 -> 用户人工微调发布。

## 当前版本能力

- Vercel 线上部署。
- 线上工作台公网跳转。
- 飞书每日内容雷达卡片。
- 页面测试飞书推送。
- PowerShell `npm.cmd run feishu:push` 推送。
- `/api/cron/daily-feishu` 定时推送。
- 飞书卡片按钮跳转公网工作台。
- 今日选题生成。
- 来源管理器。
- 公众号正文生成。
- 七七语气优化。
- 公众号排版预览。
- 本地 localhost 公众号封面上传和草稿箱写入。

## 当前限制

- Vercel 线上不稳定支持公众号封面上传和草稿箱写入，因为微信公众号接口受 IP 白名单影响。
- V1 推荐分工：线上负责选题、正文、排版、飞书入口；本地 localhost 负责公众号封面上传和写入草稿箱。
- 飞书当前是 webhook 推送，不是飞书自建应用交互卡片。
- 国内数据源如新榜、巨量、小红书、抖音指数尚未真实接入。
- 灵感池尚未开发。
- 语音输入尚未开发。
- 固定 IP 云服务尚未开发。

## 后续版本规划

V2 近期重点是灵感池：灵感记录、灵感评分、灵感转选题、灵感转大纲、灵感转公众号正文，并稳定验收飞书每日 8 点推送。

V3 中期重点是输入与数据源增强：语音输入灵感、飞书灵感同步、AI 自动封面、国内内容观察数据源接入。

V4 长期重点是线上化和增长闭环：固定 IP 云服务、线上稳定写入公众号草稿箱、飞书交互卡片、多平台矩阵内容生成、私域承接素材自动生成。
